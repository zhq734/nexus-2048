# NEXUS 2048

一个支持多种玩法、道具、AI 提示、主题切换、离线安装与本地存档的创意 2048 游戏。纯静态实现，无第三方运行时依赖。

## 功能

- **六种模式**：经典 4×4、迷你 3×3、禅意 5×5、120 秒闪电战、混沌石墙、每日确定性挑战。
- **四种道具**：撤销、打乱、锤子、冻结。
- **AI 局势提示**：基于棋盘空间、单调性、合并收益与连锁潜力给出方向建议。
- **局势雷达**：实时显示空格率、合并效率、连击与危险等级。
- **动态体验**：滑动/键盘/触屏操作、合成动画、粒子彩带、Web Audio 合成音效、震动反馈。
- **三种主题**：极光、日出、星云，支持系统明暗主题变量扩展。
- **本地数据**：按模式自动存档、生涯统计、最佳分数与设置持久化。
- **PWA 离线支持**：Service Worker 缓存应用外壳，可安装到桌面或主屏幕。
- **响应式布局**：适配手机、平板与桌面，使用 flex/grid 与动态棋盘尺寸。

## 本地运行

```bash
npm test
npm start
```

浏览器访问 <http://localhost:4173>。

## 测试

```bash
npm test
```

引擎、AI、存储模块共有 34 个单元测试，覆盖合并规则、方向移动、石墙阻断、道具、计时、每日种子、统计持久化等关键行为。

## 操作

- 方向键或 `W/A/S/D`：移动方块。
- 鼠标拖动或触屏滑动：移动方块。
- `Space`：暂停/继续。
- `N`：新游戏。
- `U`：撤销。
- `H`：AI 提示。
